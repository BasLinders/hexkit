A  statistics toolkit for experiment data analysis, hosted on Github, accessible on [Streamlit](https://hexkit.streamlit.app/).

   ## Statistical validation
   Hexkit's statistics run on [First Order Engine](https://github.com/BasLinders/first-order-engine). Its R validation notebooks, which check FOE's results against independent R implementations, live in that repository under [`r_validation/`](https://github.com/BasLinders/first-order-engine/tree/main/r_validation).
